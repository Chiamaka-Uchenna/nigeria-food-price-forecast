# Data

Raw data is not committed. The notebook downloads it into `data/raw/` on first run.

Source: [WFP food prices for Nigeria](https://data.humdata.org/dataset/wfp-food-prices-for-nigeria) (World Food Programme, via the Humanitarian Data Exchange, CC BY-IGO). 49,626 retail price records for 23 foods in 46 markets, January 2017 to November 2026.
